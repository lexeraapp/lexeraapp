**Turkish for English speakers, from first greeting to relative clauses.**<br/>
Short adaptive sessions, spaced review and a vowel harmony engine that makes suffixes feel automatic.

<br/>

### [Open the app: lexeraapp.github.io](https://lexeraapp.github.io)

<br/>

<img src="https://raw.githubusercontent.com/lexeraapp/.github/main/profile/assets/stats.svg" width="100%" alt="3 phases, 60 lessons, 480 words, 6 game types"/>

</div>

<br/>

- **Three phases:** Beginner, Intermediate and Advanced, aligned to CEFR A1 to B1.
- **Six game types:** choose, listen, match, type, build a sentence and harmony drills.
- **Adaptive:** difficulty holds you near 82 percent correct, and every word returns on a spaced schedule.
- **Private by design:** no account, no tracking. Install it to your home screen and it works offline.
